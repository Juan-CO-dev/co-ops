**Shared UI contract.** Add a pure status reducer/model in `lib/save-status-shared.ts` and one client hook/view (`components/ui/useSaveStatus.ts`, `components/ui/SaveStatus.tsx`, or the repo's equivalent naming): `idle → saving → saved | failed`, `failed → saving` on explicit retry, and a new edit invalidates `saved`. Every request has a monotonically increasing local revision; only the latest acknowledged revision may display Saved. Preserve the AM prep transport's richer `retrying` state and ensure a retrying attempt cannot say Saved while a newer edit is pending. The failed view says “Couldn't save — Try again” / “No se pudo guardar — Toca para reintentar” and exposes a real 44px, centered button; use token text roles. Avoid a timeout that silently turns a failed save into idle. A successful acknowledgement may stay visible until edit/navigation; a timer, if retained, must be cancelled on new work/unmount. Per-item status is separate from final-submit status.

**What's-left contract.** Add pure selectors in `lib/whats-left-shared.ts` over *template rows plus current form/completion state*, returning stable `{itemId, sectionId, label, targetField}` entries in template order. One reusable, collapsed-by-default summary in `components/ui/WhatsLeft.tsx` displays an i18n'd “{n} left” count; it is absent at zero. Its item buttons reveal the saved checklist section preference, scroll the **item** into view, then focus its first missing required control after render (without stealing focus on ordinary rerenders). Keep the list out of submitted/read-only phases. Use `resolveTemplateItemContent` / `resolveSectionLabel` for display, never translated labels as keys. Existing `useCollapsibleSections` remains the checklist disclosure authority; the list's own disclosure is transient `useState`. All strings and ARIA labels go into both `lib/i18n/en.json` and `es.json` in operational tú-form. Existing `CollapsibleChecklistSection` (`components/ui/CollapsibleChecklistSection.tsx`) and `docs/DISCLOSURE_DOCTRINE.md` D1–D10/D9a govern 44px controls, counts, full-row toggle, alert visibility and remembered section expansion.
