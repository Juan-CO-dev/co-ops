# Manager goals
1. * Log in.
2. * Nothing is assigned to you yet today. Take the morning report for yourself.
3. * Open the shop: check last night's count against what is really there, send in the first part, then put in the morning prep and finish it.
4. * A produce delivery just came. Check it in. One item came short (less than you ordered).
5. * The lunch rush is over. Get the line back to par.
6. * See which stations are covered right now and what is running late. Leave a note for the next shift.
7. * It's closing time. Count what is left so tomorrow's opener knows what is there.
8. * Do the night report: grade one person and pick the MVP.
9. * Record tonight's cash.
10. * Finish the closing so the day is done.
11. Start a full count of the shelves.
12. Start the next order for one vendor.
13. Find the delivery you checked in today in the reports.
