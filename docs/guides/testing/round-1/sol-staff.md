## The 5 best things CO-OPS does for a restaurant

1. **Opening Report:** Records station checks, fridge readings, counts, and prep against par, so the opening crew can hand over a clear starting picture.
2. **Closing checklist:** Tracks each station’s finished jobs with a person, time, and notes, so the key holder can see what is done.
3. **AM Prep:** Sends the closing counts to the next crew, so openers know what is left.
4. **Mid-Shift Pulse:** Shows coverage, late work, catering timing, and fridge status together, so staff can spot what needs attention.
5. **Maintenance Log:** Keeps a named, dated note about equipment trouble, so a manager has a record to follow up.
